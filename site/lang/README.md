# Sprachtabellen (V456)

`en.json` = Schlüssel → gleicher Text (Englisch ist die Quelle). Übersetzungen: `es.json`, `pt.json` (Brasilien), `de.json`, `ru.json` – gleiche Schlüssel, übersetzte Werte.

Regeln für Übersetzer:
- Platzhalter unverändert lassen: `#` (Zahl), `@` (Name eines Ortes/Kontinents/Monsters/Gadgets), `·` (Trenner), `▶`, `×`, `%`, `★`, `☠`, `♥`, Emojis.
- Groß-/Kleinschreibung wie im Original: GROSSBUCHSTABEN bleiben GROSS (Titel, Knöpfe), Satz bleibt Satz.
- Kurz halten: Knopf- und Titeltexte (GROSS, ≤ 3 Wörter) höchstens +20 % länger als das Englische; sonst höchstens +30 %. Lieber ein knappes Wort als die wörtliche Übersetzung.
- Figuren bleiben: Rosie, Blue, General Bristle, Major Ledger, Doc Hazel, Coach Ollie, Capybara Squad, NUTS, SKULLGROG, GORKAZAR, FROSTGNAW, GRUMBLEFANG, Capybara World.
- Spielbegriffe (einheitlich!): Splat → ES «Splat»/«aplastar» … je Sprache ein fester Begriff wählen und durchziehen; Wave = Welle/ola/onda/волна; Tower = Turm/torre/torre/башня; Gold = Gold/oro/ouro/золото; Lives = Leben/vidas/vidas/жизни; Ring = Ring/anillo/anel/кольцо; Ten-ton drop, Sniper strike, Concrete mixer, Tesla storm, Chomper, Lockdown, Wolf call, Lucky Supply, Air Drop, Boss hack, Daily Drop, Daily Mission, Nuts detour, World tour, Squad, Medal → sinnvoll übersetzen, kurz, in Spiel-Tonfall.
- Ton: locker, freundlich, Gamer-Sprache, 13+, kein Militär-Jargon, keine Kraftausdrücke. Anrede: DE «du», ES «tú», PT-BR «você», RU «ты».
- Sprachclips (kurze Rufe wie «Splat!», «Incoming!», Sprüche von Rosie & Blue) so übersetzen, dass sie gesprochen gut klingen.
- Keine HTML-Tags, keine Anführungszeichen hinzufügen. Eigennamen/Jargon-Reste wie «GGGGGGGGGG» unverändert lassen.
